# EML to PDF Converter

## Quick Start Guide (Beginner Friendly)

1. Install **Node.js** (LTS version) from https://nodejs.org/
2. Open this folder (`eml-to-pdf-app`) in **VS Code**.
3. Open the VS Code Terminal (`Terminal` -> `New Terminal` from the top menu).
4. Run this command to install required packages (takes ~1-2 minutes):
   ```bash
   npm install
   ```
5. Start the app:
   ```bash
   npm start
   ```
6. Open your browser and go to: **http://localhost:3000**
7. Upload the included `sample-email.eml` file to test!
